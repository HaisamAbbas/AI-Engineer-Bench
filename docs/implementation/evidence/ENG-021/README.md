## Three-Label Discipline

- **`official-public-origin`**: The 12 existing development tasks. Private examples generated on these tasks do NOT constitute a contamination-free hidden benchmark (§22).
- **`official-held-out`**: Genuine held-out family requiring distinct application packages. **OUT OF SCOPE** — not yet created.
- **`development`**: Local scratch/development only. Never used for official purposes.

## Key Decisions

1. **No release manifest before review**: Used `examples/proposed-release-candidate.json` with `pending-independent-review` status per DECISIONS.md ENG013-004.
2. **Assumption-based sample sizes only**: No deterministic fixture results used for variance estimation. Wilson interval / MDD table across assumed pass rates. Real pilot variance unavailable (ENG-012 BLOCKED).
3. **5 reps not statistically powered**: MDD ≈ 0.62 >> MME 0.10. Campaign proposal must be revised after ENG-012 authorization.
4. **Bundle excludes protected paths**: `build_release_bundle.py` has a test asserting no `tests/maintainer/` paths and no holdout paths.
5. **Audit reports evidence, never verdicts**: `audit_prerequisites.py` surfaces all gaps as open items, never produces "approved"/"ready" verdicts.
6. **Retention clause**: Cites ENG-011's `execution_valid`/`scored` populations — valid failures retained as scored FAIL; infra-invalid attempts retained for attribution but excluded from `cost_per_resolution`.
