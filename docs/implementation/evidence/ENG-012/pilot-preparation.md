# ENG-012 development-pilot preparation

`examples/development-pilot-18.json` freezes an offline 3-task × 2 deterministic development-fixture entrant × 3 repetition matrix (18 cells). It validates the matrix shape and records `prepared-not-authorized` rather than a result.

The real-agent pilot was **not run**. There is no explicit provider/cloud authorization, credential, or approved spend cap; provider/model settings and enforceable cost reservation therefore cannot be resolved honestly. The manifest is executable only as offline deterministic fixture preparation, not a substitute for a real development campaign. A real pilot requires an authorized provider/model configuration, fixed application profiles, a concrete cap/reservation policy, and the real-agent ENG-001 smoke gate.
