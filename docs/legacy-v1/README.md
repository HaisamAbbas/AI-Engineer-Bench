sequence. They remain in the repository for historical provenance and Git
history, but are not active product specifications.

specification and prompt pack. Use `docs/implementation/REDESIGN_SCOPE.md` and
`V2_CODE_CLEANUP_MANIFEST.md` for the active boundary and cleanup status.
